# Sprint 01 — Project Setup & Basic Chatbot

**Project:** AI Fitness Assistant  
**Sprint:** 01  
**Status:** Completed

## Sprint Objective

Establish the foundational application structure and develop a basic interactive chatbot using Python and Streamlit.

## User Stories

- As a user, I want to interact with a chatbot through a simple interface so that I can ask questions.
- As a developer, I want a structured Python environment so that application dependencies can be managed independently.

## Key Deliverables

- Created the Python project structure.
- Configured a Python virtual environment.
- Installed Streamlit and required dependencies.
- Developed a basic chatbot interface.
- Implemented conversation history using Streamlit session state.
- Enabled user input through the chat interface.

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Application development |
| Streamlit | Interactive web interface |
| Git | Version control |
| GitHub | Source code management |

## Acceptance Criteria

- [x] Application launches successfully.
- [x] Chat interface is displayed.
- [x] User can enter messages.
- [x] Conversation history is maintained during the session.

## Sprint Outcome

Successfully established the foundational application and a working interactive chatbot interface.

## Next Sprint

Integrate an LLM using the OpenAI API to generate intelligent responses.
